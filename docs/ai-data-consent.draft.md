# Git 작업 데이터 및 기능명세서의 외부 AI 처리·국외 이전 동의서

갈피(Galpi)는 사용자가 연결한 Git 저장소의 작업 내역과 등록한 기능명세서를 분석하여 PR 요약, 코드 변경사항 분석, 기능별 작업 내역 정리 등의 AI 기반 기능을 제공하기 위해 외부 AI 서비스를 이용합니다.

이에 따라 사용자가 연결한 저장소의 일부 정보가 외부 AI 서비스 제공업체로 전송될 수 있습니다. 아래 내용을 확인한 후 동의 여부를 선택해 주세요.

## 1. 외부 AI를 이용하는 목적

갈피(Galpi)는 다음과 같은 기능을 제공하기 위해 외부 대규모 언어 모델(LLM)을 이용합니다.

- 기능명세서 PDF에서 기능 항목 추출
- Pull Request 내용 및 변경사항 분석
- Commit 및 개발 작업 내역 분석
- 코드 변경사항(Diff) 분석 및 요약
- 사용자별 또는 기능별 작업 내역 정리
- 저장소의 개발 이력 및 구현 내용 요약
- 사용자가 요청한 Git 저장소 관련 AI 분석 기능 제공

외부 AI로 전송된 정보는 위 분석 결과를 생성하기 위한 목적으로 사용됩니다.

## 6. 민감정보 및 비밀정보가 포함된 저장소 이용 시 주의사항

저장소 및 기능명세서에 다음 정보가 포함되지 않도록 주의해 주세요.

- 비밀번호, API Key
- Access Token 또는 Refresh Token
- Secret Key, 인증서 또는 Private Key
- 데이터베이스 접속정보
- 개인정보 또는 민감정보
- 외부 전송이 금지된 회사·조직의 영업비밀 또는 기밀정보

사용자는 연결한 저장소를 본 서비스로 분석할 적법한 권한이 있는지 확인해야 합니다.

회사, 학교, 단체 또는 다른 사람이 소유한 Private Repository를 연결하는 경우 해당 조직의 보안정책, 개인정보 처리정책 및 내부 규정을 확인해 주세요.

## 7. 다른 기여자의 정보

Git 저장소에는 사용자 본인 이외의 개발자가 작성한 Commit, PR, 리뷰, 댓글 및 작성자 정보 등이 포함될 수 있습니다.

사용자는 해당 저장소를 분석할 권한이 있는지 확인해야 합니다. 다른 사람의 개인정보 또는 외부 제공이 제한되는 정보가 포함된 경우 관련 법령 및 소속 조직의 정책을 준수해야 합니다.

## 8. 동의 거부 및 철회

사용자는 외부 AI 서비스로의 정보 전송 및 개인정보 국외 이전에 대한 동의를 거부할 수 있습니다.

동의하지 않으면 다음 AI 분석 기능의 이용이 제한됩니다.

- 기능명세서 PDF의 AI 기능 항목 추출
- PR 및 Commit AI 분석
- 코드 변경사항 AI 분석
- 개발 작업 내역 자동 요약
- 기타 외부 AI를 이용하는 분석 기능

기능명세서 등록 전 동의를 취소하면 PDF를 전송하지 않으며, 명세서 없이 프로젝트 생성을 계속할 수 있습니다.

저장소 연결 화면에서 동의를 취소하면 저장소 연결과 분석 요청을 진행하지 않습니다. 기존에 생성한 프로젝트는 유지됩니다.

사용자는 **[미정: 갈피 문의처 및 실제 동의 철회 경로]**를 통해 향후 외부 AI 분석에 대한 동의를 철회할 수 있습니다.

동의 철회 이전에 적법하게 처리된 정보에는 동의 철회의 효력이 소급 적용되지 않습니다.
